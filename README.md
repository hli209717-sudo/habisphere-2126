# 寰生未来 HabiSphere · 2126 —— 发布会级网页演示

一套 20 页的虚构未来科技企业战略发布演示（网页版）。深海军蓝 × 冰蓝 × 生态绿的硬科幻视觉体系，全屏 16:9 自适应缩放、键盘/滚轮/触摸翻页。

## 四个版本

| 版本 | 入口 | 动效风格 |
|---|---|---|
| **Video 视频版（实拍动效）** | `video.html` | Impact 全套元素动画 + 6 段视频替换原静态图（封面/工厂/能源/生活/轨道/月球），活动页自动循环播放，切页自动启停 |
| **Impact 冲击版（创意编排）** | `impact.html` | 标题光擦揭示、卡片按左右半屏对称飞入合拢、图片幕布展开、页眉弹落、数字滚动+辉光 |
| Cinematic 舒适版（默认首页） | `index.html` | 大字模糊聚焦、卡片上浮、数据条生长、页间柔和交叉淡化 |
| Classic 经典版 | `classic.html` | 优雅级联淡入，节奏克制 |

> 本项目为**虚构企业情景设定**（2126 年架空世界），所有产品、数据均为创作内容，不代表任何真实企业。

## 技术说明

- 单文件零依赖、零构建，页面内容作用域化合并自 20 页幻灯片
- Cinematic 版动效：按元素类别编排（标题 blur-in / 卡片 rotateX 3D 翻入 / 图片 Ken Burns / 数字 count-up），页间 scale+blur 景深推拉，逐元素 80ms 级联延迟
- 自适应：1280×720 设计稿等比缩放，任意窗口尺寸 letterbox 居中
